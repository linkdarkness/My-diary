Comment Héberger ce jeu sur GitHub Pages ?

Ce jeu est conçu comme un fichier HTML unique autonome sans aucune dépendance serveur requise.

  1. Créez un dépôt GitHub public (ex: mon-rpg-idle).
  2. Enregistrez ce code complet dans un fichier nommé index.html.
  3. Uploadez ou pushez ce fichier index.html à la racine de la branche main.
  4. Dans GitHub, allez sur votre dépôt dans Settings > Pages.
  5. Sous "Build and deployment / Source", choisissez Deploy from a branch et sélectionnez main.
  6. Cliquez sur Save. En 1-2 minutes, votre jeu sera en ligne gratuitement !
